# Expressive Studio 1.0.1

Мод Spicetify с полноценным редактором внешнего вида. Наш Material 3 Expressive перенесён внутрь мода; отдельная тема в `Themes/ExpressiveMotion` больше не нужна.

## Уже есть

- Одна кнопка **«Оформление»** справа сверху открывает всплывающий редактор. Есть дополнительный вход через **Профиль → Expressive Studio**. Отдельной страницы и кнопки в навигации Spotify нет.
- Исходный профиль Material 3 Expressive и 16 цветовых пресетов с мини-превью.
- Цвета из обложки или свои цвета акцента, фона, панелей и плеера.
- Отступы, углы, плотность карточек, размеры плеера, обложки и кнопки Play. Связанные размеры ограничиваются так, чтобы управление помещалось в плеер.
- Roboto Flex, Spotify Mix, Segoe UI или системный шрифт; масштаб и насыщенность текста.
- Живой фон Material, своё изображение или их сочетание. Размытие и яркость применяются только к изображению фона.
- Формы Cookie/Sunny/Clover, морфинг, вращение, темп, количество малых форм, движение обложек и волнистый прогресс.
- До 64 своих профилей: сохранение, переименование, переключение, удаление с отменой, импорт и экспорт JSON.
- Отмена и повтор изменений; перетаскивание одного ползунка считается одним действием.
- Мгновенное выключение оформления с возвратом к обычному Spotify. Редактор остаётся доступным.

Настройки применяются сразу и сохраняются автоматически. Перезапуск нужен только при первой установке или обновлении самого пакета.

## Установка / обновление

Spicetify должен быть уже установлен и работать. В PowerShell из папки мода:

```powershell
.\Install.ps1
```

Команда установит одно расширение, создаст резервную копию, отключит прежнюю тему и применит мод. Старые каталоги `Themes/ExpressiveMotion` и `CustomApps/expressive-studio` перемещаются в резервную копию после успешного применения. При обновлении с версии 1.0 исходная резервная копия сохраняется.

Чтобы применить файлы без автоматического перезапуска:

```powershell
.\Install.ps1 -NoRestart
```

Затем полностью перезапусти Spotify сам. Настройки `expressive-motion:v1` автоматически копируются при первом запуске в новое хранилище; старые данные сохраняются для отката.

Устанавливается файл `Extensions/expressive-studio.js`. Отдельной темы, Custom App и ручного копирования CSS не требуется. Marketplace, другие приложения и расширения сохраняются. Из `custom_apps` удаляется только прежний `expressive-studio`.

## Откат

Из этой же папки:

```powershell
.\Install.ps1 -Restore
```

Возвращаются предыдущие настройки, сохранённая тема и прежняя версия расширения, если она была. Из списков приложений и расширений удаляются только записи нашего мода, отсутствовавшие до установки; добавленные позже сторонние моды сохраняются. Резервная копия остаётся в `mod-backups/ExpressiveStudio` рядом с конфигурацией Spicetify. Пользовательские профили и изображения мода не удаляются.

## Профили и изображения

В окне редактора **Esc** закрывает окно, **Tab** перемещает фокус между его элементами. **Ctrl+S** открывает сохранение профиля; **Ctrl+Z** отменяет изменение, **Ctrl+Shift+Z** повторяет. При редактировании текстового поля обычная отмена текста сохраняется.

Импорт принимает только формат `expressive-studio`, версию 1 и известные параметры. CSS и JavaScript из файлов не выполняются. Поддерживаются PNG, JPEG и WebP до 4 МБ; SVG и внешние URL не принимаются. Изображения хранятся локально в IndexedDB, профили — в localStorage. Экспорт включает необходимые изображения с проверяемыми контрольными суммами. Максимум файла импорта — 12 МБ; большие библиотеки с разными изображениями экспортируются по отдельным профилям.

## Границы

Мод использует интерфейс Spotify и API Spicetify. Обновления Spotify могут потребовать адаптации. Нативные кнопки Windows не заменяются: доступен только тональный фон их области. Отдельный Windows-мод не устанавливается.

Исправление приглушения сохранено: служебные слои Spotify не оформляются как панели. Глобальной приостановки всех анимаций Spotify больше нет — останавливаются только анимации нашего оформления.

В Spicetify 2.46 подмена базовых цветов отключается при пустом `current_theme`. Поэтому мод самостоятельно подставляет цветовые роли в загруженные стили Spotify и возвращает исходные значения при выключении. Файлы Spotify при этом не переписываются. Правила, которые после нас изменило другое расширение, не откатываются.

## Исходники и сборка

`source/` содержит исходники движка, редактора, валидатора, профилей и тесты. `Extensions/expressive-studio.js` — готовый мод, включая все шрифты и графику внутри сборки. Для установки Node.js не нужен. Сторонние CDN, аналитика и сервер мода отсутствуют.

```sh
cd source
npm ci
npm test
npm run build
```

Движок: `main.js`, `appearance.js`. Состояние: `config.js`, `store.js`, `assets.js`. Совместимость с панелями: `compatibility.js`. Редактор: `editor.jsx`, `editor.css`.

Подготовлено для Spotify 1.3.6.1921 / Spicetify 2.46.2. Локальные проверки формата профилей, миграции и отмены выполняются отдельно от Spotify. **Визуальная и функциональная приёмка внутри Spotify оставлена пользователю; Spotify автоматически не запускался для проверки.**
